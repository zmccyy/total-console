# 总控台

单机、单用户的 Windows 本地开发运维面板：自动扫描本机的服务进程、监听端口、项目目录与已安装的 Agent 工具，聚合为统一面板，并以用户保存的命令启停任务。仅绑定回环地址，不对网络提供任何服务。

功能复刻自 [laogou717/local-ops](https://github.com/laogou717/local-ops)（macOS 版「总控台」），按 Windows 适配：Python 标准库 + psutil 的模块化后端，无构建、无 CDN 的原生前端。

## 快速开始

要求：Windows 10/11、Python 3.10+、`pip install psutil`。

```
start.bat            # 双击或命令行启动，自动打开 http://127.0.0.1:9600
python server.py --no-browser            # 不自动开浏览器
python server.py --port 9603             # 指定首选端口（被占则尝试 9601–9609）
python server.py --data-dir <PATH>       # 自定义数据目录
```

数据目录默认 `%APPDATA%\总控台`：`config.json`（写入前自动留 `config.json.bak` 备份）、`logs/`（各单元日志，按 2 MB 上限裁剪）。

## 功能

- **启动台**：保存常用服务（长期运行）与任务（一次执行），一键启动 / 停止 / 重启 / 查日志 / 诊断 / 编辑 / 删除；卡片支持拖拽与键盘（Ctrl+←/→）排序，分区筛选、批量停止。
- **环境变量**：单元可配置 `env` 键值对与 `.env` 文件（相对工作目录），启动时按「进程环境 ⊂ .env ⊂ 手写值」合并注入；卡片显示 ENV 徽章，.env 缺失给非阻断提醒。
- **终端 / 编辑器一键打开**：卡片「❯」「⌨」在 Windows Terminal（回退 cmd）或 VS Code（回退资源管理器）中打开单元工作目录。
- **端口一键打开 / 复制 URL**：运行单元的 TCP 端口与监控页项目端口可直接在默认浏览器打开或复制地址。
- **运行令牌 + 三重校验**：启动时向命令行注入随机令牌，停止时校验令牌 + 进程创建时间 + 当前用户，不会误杀同名同端口的无关进程。优先使用 PowerShell 7（pwsh）执行，未安装回退 5.1。
- **服务监控**：每 2 秒刷新本机监听端口（已管理 / 项目 / 其他三档归属）、CPU、内存与进程表；端口属主带**启动者溯源**徽章（Codex / Claude Code 等 AI 助手、VS Code / Cursor 等编辑器、终端或总控台自身）；侧栏带 CPU / 内存**负载曲线**（近 120 帧）。
- **进程关注列表与隐藏**：设置关键字（匹配进程名 / 命令行）在监控页独立分组展示；不需要的进程按名隐藏、设置中一键恢复。
- **新端口发现**：持久化端口基线；新出现且非本控制台管理的监听端口在页面顶部提醒，可一键「加入启动台」（认领进程）或「忽略并隐藏」（设置中可恢复）。
- **认领**：把已在运行的外部进程（当前用户）绑定为受管单元，原子校验防重复认领。
- **健康检查与诊断**：启动前静态检查工作目录 / 运行时 / 脚本（卡片显示「⚠ 需检查」）；诊断给出依赖缺失、端口占用、npm 脚本名错误等可执行的修复建议，依赖缺失支持**一键安装**（创建一次性任务并跳转日志观察）。
- **命令面板**：`Ctrl+K` 全局搜索与快捷操作（启停、跳转、主题、批量停止、终端/编辑器打开）。
- **日志中心**：`Ctrl+J` 聚合全部命令单元日志，3 秒自动刷新。
- **任务完成通知**：任务结束 / 服务意外退出时弹浏览器通知（设置中可关）。
- **盘点**：Agent 工具注册表盘点（版本 / 安装路径 / 登录态）+ 扫描根内的项目识别、候选启动命令与 **Git 分支 / 脏状态**徽章。
- **总控台自身控制**：顶栏「重启 / 停止」只影响面板服务，不影响已运行的命令单元；重启为新进程接管同端口，页面自动恢复。

## 安全边界

- 只添加你已检查且信任的命令和工作目录；总控台能以当前用户权限执行保存的 shell 命令。
- 仅绑定 `127.0.0.1`；写接口要求 Host 校验（防 DNS rebinding）+ 同源 Origin + 操作令牌三重防护。
- 「打开 URL」接口仅接受 http/https 地址；「打开终端 / 编辑器」只对已保存单元的工作目录执行白名单程序。
- 不通过反向代理、SSH 隧道或端口映射对外暴露；不要在共享或不受信任的用户账户中运行。
- 配置、日志可能含本机路径等敏感信息，上传前请脱敏。

## 开发

```
python -m pytest tests/ -q    # 全量测试（106 项，含前端契约测试）
python tools/smoke.py         # 前后端联通性冒烟（38 项，真实服务器）
```

结构：`core/server.py`（HTTP 骨架：鉴权 / 分发 / 静态文件）、`core/api/`（按域注册的 API 路由：snapshot / units / settings / inventory / console）、`core/launchpad.py`（命令单元与进程管理）、`core/scanner.py`（进程/端口快照，Windows 原生批量枚举 + psutil 回退）、`core/attribution.py`（进程溯源）、`core/diagnose.py`（健康检查与诊断）、`core/inventory.py`（Agent 工具与项目盘点，含只读 Git 信息）、`core/integrations.py`（终端 / 编辑器集成）、`core/security.py`（Host/Origin 校验）、`core/store.py`（配置持久化与 schema 迁移）、`static/js/`（原生 ES Modules 前端）、`registry/agent-tools.json`（Agent 工具注册表）、`tools/smoke.py`（联通性冒烟）。

版本号以根目录 `VERSION` 为单一权威来源；变更记录见 [CHANGELOG.md](CHANGELOG.md)，术语表见 [CONTEXT.md](CONTEXT.md)。
