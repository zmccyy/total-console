# 总控台

单机、单用户的 Windows 本地开发运维面板：自动扫描本机的服务进程、监听端口、项目目录与已安装的 Agent 工具，聚合为统一面板，并以用户保存的命令启停任务。仅绑定回环地址，不对网络提供任何服务。

功能复刻自 [laogou717/local-ops](https://github.com/laogou717/local-ops)（macOS 版「总控台」），按 Windows 适配：Python 标准库 + psutil 的模块化后端，无构建、无 CDN 的原生前端。

## 快速开始

要求：Windows 10/11、Python 3.10+、`pip install psutil`。

```
start.bat            # 双击或命令行启动，自动打开 http://127.0.0.1:9600
python server.py --no-browser            # 不自动开浏览器
python server.py --port 9603             # 指定首选端口（被占则尝试 9601–9609）
python server.py --data-dir <PATH>       # 自定义数据目录
```

数据目录默认 `%APPDATA%\总控台`：`config.json`（写入前自动留 `config.json.bak` 备份）、`logs/`（各单元日志，按 2 MB 上限裁剪）。

## 功能

- **启动台**：保存常用服务（长期运行）与任务（一次执行），一键启动 / 停止 / 重启 / 查日志 / 诊断 / 编辑 / 删除；卡片支持拖拽与键盘（Ctrl+←/→）排序，分区筛选、批量停止。
- **运行令牌 + 三重校验**：启动时向命令行注入随机令牌，停止时校验令牌 + 进程创建时间 + 当前用户，不会误杀同名同端口的无关进程。
- **服务监控**：每 2 秒刷新本机监听端口（已管理 / 项目 / 其他三档归属）、CPU、内存与进程表；端口属主带**启动者溯源**徽章（Codex / Claude Code 等 AI 助手、VS Code / Cursor 等编辑器、终端或总控台自身）。
- **新端口发现**：持久化端口基线；新出现且非本控制台管理的监听端口在页面顶部提醒，可一键「加入启动台」（认领进程）或「忽略并隐藏」（设置中可恢复）。
- **认领**：把已在运行的外部进程（当前用户）绑定为受管单元，原子校验防重复认领。
- **健康检查与诊断**：启动前静态检查工作目录 / 运行时 / 脚本（卡片显示「⚠ 需检查」）；诊断给出依赖缺失、端口占用、npm 脚本名错误等可执行的修复建议。
- **命令面板**：`Ctrl+K` 全局搜索与快捷操作（启停、跳转、主题、批量停止）。
- **日志中心**：`Ctrl+J` 聚合全部命令单元日志，3 秒自动刷新。
- **任务完成通知**：任务结束 / 服务意外退出时弹浏览器通知（设置中可关）。
- **盘点**：Agent 工具注册表盘点（版本 / 安装路径 / 登录态）+ 扫描根内的项目识别与候选启动命令。
- **总控台自身控制**：顶栏「重启 / 停止」只影响面板服务，不影响已运行的命令单元；重启为新进程接管同端口，页面自动恢复。

## 安全边界

- 只添加你已检查且信任的命令和工作目录；总控台能以当前用户权限执行保存的 shell 命令。
- 仅绑定 `127.0.0.1`；写接口要求 Host 校验（防 DNS rebinding）+ 同源 Origin + 操作令牌三重防护。
- 不通过反向代理、SSH 隧道或端口映射对外暴露；不要在共享或不受信任的用户账户中运行。
- 配置、日志可能含本机路径等敏感信息，上传前请脱敏。

## 开发

```
python -m pytest tests/ -q    # 全量测试（85 项）
```

结构：`core/server.py`（HTTP 服务与路由）、`core/launchpad.py`（命令单元与进程管理）、`core/scanner.py`（进程/端口快照，Windows 原生批量枚举 + psutil 回退）、`core/attribution.py`（进程溯源）、`core/diagnose.py`（健康检查与诊断）、`core/inventory.py`（Agent 工具与项目盘点）、`core/security.py`（Host/Origin 校验）、`core/store.py`（配置持久化与 schema 迁移）、`static/`（原生前端）、`registry/agent-tools.json`（Agent 工具注册表）。
